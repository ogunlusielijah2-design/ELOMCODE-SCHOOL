01 UNDERSTAND THE CONCEPT

What You Need To Know

CORE CONCEPT
CSS stands for Cascading Style Sheets. CSS is the language used to control how HTML elements look on a webpage. While HTML gives a webpage its structure, CSS controls things such as colors, spacing, fonts, borders, sizes, positioning and layout.
WHY?
Why does this matter?

CSS allows you to transform plain HTML into a visually organized, attractive and responsive interface.

02 LEARN THE SYNTAX

CSS Structure

CSS
CSS rules normally contain a selector, followed by declarations inside curly braces. 
selector {
    property: value;
}
selector Selects the element you want to style.
property Describes what you want to change.
value Specifies the value of that property.
